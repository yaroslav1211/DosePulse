# DosePulse

Водопʼянов Ярослав Сергійович, ІО-32.

Обліковує послідовні порції сипкого матеріалу за приростом маси, таруванням та вікном стабілізації.

Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi. Плата Nucleo-C031C6, форма B.

## Стан

Підготовлено тему, чернетку PRD та базовий UART/LED-шаблон. Прикладну логіку й драйвери компонентів не реалізовано. Збірку цієї копії, симуляцію та лабораторні ще не перевірено. Git/GitHub налаштовує власник.

## Базова збірка

```sh
make build
```

Команда має створити `firmware/build/firmware.elf`, `.hex` та `.bin`; для цієї копії результат ще не отримано. Звичайний `wokwi.toml` посилається на ці файли. Початкова схема містить тільки плату та UART. Склад компонентів нижче є планом підключення у ЛР2.
